# Rush02 教材版の読み方

このフォルダは、提出用 `ex00/` と同じ処理を、日本語コメントを増やして
読みやすくした教材版です。

## おすすめの読む順番

1. `main.c`：プログラム全体の流れ
2. `input.c`：コマンドライン引数の確認
3. `read_dict.c`：辞書ファイルを最後まで読む
4. `parse_dict.c`：辞書を1行ずつに分ける
5. `parse_line.c`：`42 : forty two` をキーと値に分ける
6. `dict_utils.c`：辞書から単語を探す・解放する
7. `convert.c`：大きな数を3桁ずつに分ける
8. `convert_group.c`：3桁以下を英単語へ変える
9. `append.c`：見つけた単語を結果へ足す
10. `utils.c`：小さな共通関数

## 重要なポインタの意味

- `char *number`：数字の文字列。例は `"42"`。
- `char **entry`：辞書の1行。`entry[0]` がキー、`entry[1]` が値。
- `char ***dict`：辞書全体。たくさんの `entry` を持つ。
- `char **result`：呼び出し元の結果ポインタを書き換えるための住所。

## 提出時の注意

提出するのは隣の `ex00/` です。この教材版はコメントによって関数が
25行を超えるため、そのまま提出しないでください。

ボーナスの標準入力 `-`、カンマ、`and`、ハイフンはまだ未実装です。
必須部分を理解してから別機能として足すのがおすすめです。
